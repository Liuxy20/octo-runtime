# 交付与证据

> 2026-10-25：下文为 #173 历史记录。用户已否决自实现 Client，并要求使用最新版官方 TypeScript Client。当前替换方案见[官方 Client 接入](../../tasks/17-dsh-official-client/brief.md)；以完整 Provider 依赖为由重写协议客户端的决定不再适用。

用户授权从最新 main 新建 worktree，实现、审查、端到端测试并提交 PR 合并。先形成 [OctoSpec](../../tasks/17-dsh-adapter/brief.md) 与 95/100 实施准备度评估，再实现独立 dsh 包、SDK 公开入口、CLI 内置发现及共同错误/日志接线。既有 Gateway 不解析 DSH 原生轨迹。

固定支持 0.2.1-rc.3。每 invocation 独占 SDK 子进程；Desktop 仅提供 Electron 和内嵌 CLI，复用用户登录。官方 client 强依赖完整 Provider，故低层 wire client 直接复用 Runtime 有界 reader、DriverQueue 和 processCleanup，不隐式安装。prompt ACK 仅入队；receipt、root turn/end、非空已提交回答、wait 和回收分别确认。无审批传输，只接受显式 full_access；compact stream 只在消息提交后可用，不承诺实时逐 token。

真实 Desktop 新建/持久恢复、工具文件、取消/兄弟任务/恢复通过；公开发行包仓外离线安装后 SDK 和隔离 CLI Kernel 调用通过。真实 SDK/CLI Gateway 群 @、缺 @ 拒绝、续聊、工具/进度/终态/失败卡、unload/reload 通过。DM 被测试服务 not_friend 拒绝，未更改好友关系；Windows DSH 未验证。Issue 17 保持开放。完整命令、审查修复、基线和证据边界见 [acceptance.md](../../tasks/17-dsh-adapter/acceptance.md)。

# 可复用经验

必须用选定版真实工具轨迹核对 arguments JSON 字符串、toolCallId、私有 reasoning provenance，不能以旧 SDK 或模拟事件代替。版本探针也须具备 invocation 取消和树回收；enqueue/idle/EOF 不代表成功。队列首错和清理期晚到取消不能覆盖已观察失败。持久 resume 后需要重新应用本轮 cwd。原生诊断通过 invocation context 接回现有受控日志，公共卡片仍只展示标准失败目录。
