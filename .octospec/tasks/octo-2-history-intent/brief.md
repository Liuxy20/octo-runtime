# 目标与归属

先提问、再单独 mention 是有效的群聊交互。当前三处历史指引把历史作为背景与禁止执行历史指令绑定，可能让模型忽略仍有效的提问；目前没有实验证实它是唯一原因。需求来自 Loop OCTO-2 / GitHub #213。

业务决定权在 Channel Gateway：它拥有 IM 场景的材料和指引；当前消息、发送者、时序、历史范围及实际历史文本是显式输入。模型结合对话判断当前意图。Gateway 不实现意图分类，不自动重放历史请求。Core、Kernel、Adapter 和其他 Extra 不改变默认策略。

## 范围外与风险

不改协议、mention 准入、检索窗口、游标、重试、session 生命周期、工具权限或生产部署。无数据迁移；回滚三处指引即可。更开放的对话理解可能误复活旧任务，因此取消、完成、reset 和注入是独立硬门槛。compact 文案增加字节可能使近预算降级更早省略，必须用边界回归验证并明确记录。
