# 未决项与可推进工作

M1和隔离回归可按现有源码开始，不依赖部署变更。用户随后提供测试站、Bot账号和UK用户权限，已启动真实Codex端到端验证，见[live记录](live-verification.md)。M2仍需IM服务维护角色落实revision、reason12机器合同和presence过期；M5仍需睡眠/自启及其他平台、事故Provider的执行条件。缺少这些信息时继续可独立推进的工具和回归工作，G03/G04/G08及未执行真机格保持BLOCKED或NOT_RUN。准备度仍为95/100，不因提供账号就把整项E20记为具备。

未确认的原事故根因不做预评分；只有旧代码失败、新代码通过的复现才能支持某项修复。PR96或本轮受控回归通过都不能证明一小时合盖、原生登录自启和全部Provider已通过。
