## 风险与约束

- CODEX_HOME 显式注入会改变既有 SDK 零参数用法，必须提供迁移说明；CLI 在宿主保留默认选择，不把新参数强推给普通用户。
- 共享 owner 与独立 scope 混用可能误关兄弟调用；最小依赖不包含全局 close，专测 A03/A11。
- 现有 channel 与 service 紧耦合，接口提取不是单纯移动 spawn；M0 必须先验证，再迁移托管行为。
- deadline 时间原点和迟到 acquire 可能造成泄漏；必须以 barrier/清理失败证据核实，不以超时返回代表退出。
- 本次属于架构边界细化；只有代码、公开类型、实际装配和 docs 的生命周期说法一致，才满足实施验收。增加测试数量或规划得分不替代所有权正确性。
