# 可执行性：100/100

分母仅为 #110 的核心修复：省略 `allowed_sender_ids` 时，群聊和子区的非 owner 用户或其他 Bot 携带有效原生 mention，可以触发接收 Bot 的 AgentRun。DM 与卡片同源默认值一并对齐，不增加好友权限中心或跨 Bot 治理。

| 维度 | 得分 | 依据 |
| --- | --- | --- |
| 根因与复现 | 20/20 | 两处 owner 回退已定位，新增准入及传输回归在旧实现失败，修复后通过 |
| 需求与责任归属 | 20/20 | 用户已明确省略、显式及空名单语义；平台准入与 Channel 发送者策略分别负责 |
| 实现范围 | 20/20 | 仅修改 Gateway 现有入口与内部参数，无新 API、协议、Provider 依赖或部署拓扑 |
| 边界完整性 | 20/20 | 自消息、Space、群范围、原生 mention、卡片操作者及每 Bot/频道会话隔离保留 |
| 验收可执行性 | 20/20 | 有发送者矩阵、加密 WS、原生 handoff、卡片及五 Bot 群/子区回归，使用 fake Provider |

此分数是方案可执行性的工程判断，不表示线上事故已恢复、远端 CI 已通过或成功概率为 100%。已知实现缺口没有待定关键决策；后续发现的新证据仍须重新评估。

## 已实施

- 入站和卡片回调删除省略配置时的 owner 默认；显式名单及空名单仍生效。
- 架构、Channel 规则、Schema 描述、README 和 CLI/SDK 双语接入文档同步。
- 五 Bot 回归覆盖非 owner 用户/Bot 在群聊和子区通过真实 mention 触发；只点名 B 的 reset、stop 及后续请求不影响另外四个 Bot。reset 不取消原 Run，后续使用新会话与代次。

完整检查结果维护在[验证记录](../../journal/shared/2026-10-22-channel-default-admission.md)。

## 剩余交付与证据

1. 用户已授权提交、推送、创建修复 PR 并在门禁满足后合并 main；远端 CI、审批和合并状态以关联 PR 为准。
2. 尚未部署修复并用实际发送端/接收端验证原截图对应的群聊 handoff。已有日志不支持复原该消息是否到达及具体拒绝原因。
3. 平台 DM 好友/共同空间策略的真实部署未联验；这是平台准入证据边界，不作为本次群 mention 根因修复的待设计项。

`/stop`、`/reset` 在被点名 Bot 的当前频道内采用共享会话语义，与卡片仅原发起者可操作不同；本次不改变该产品策略，也不将它列为 #110 的缺陷或交付阻塞。用户已明确多个 Bot 必须隔离，新回归覆盖该边界。compaction 按用户原要求以模型为准，不纳入 gap 或新增验证。
