# Independent Channel Gateway

[简体中文](../../../zh-CN/guides/harnesses/channel-gateway.md)

Channel SDK, CLI, configuration and business dependencies now belong to [octo-channel-gateway](https://github.com/Mininglamp-OSS/octo-channel-gateway).

`ChannelRegistry.register(endpoint, definition)` connects to an existing Kernel through the public octo-runtime-client. Gateway owns its configuration and lifecycle.
